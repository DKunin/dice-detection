# Тест модели Roboflow

Изолированный CLI для сравнения локальной ONNX-модели с публичной моделью
[`dnd-dices-ycaiz/2`](https://universe.roboflow.com/dnd-dices/dnd-dices-ycaiz/model/2),
которая распознаёт `d4`, `d6`, `d8`, `d10`, `d12` и `d20`.

Inference выполняется удалённо через Roboflow Serverless API. Для запуска нужен API-ключ
Roboflow; запросы могут расходовать лимит аккаунта. Ключ передаётся в HTTP-заголовке и не
выводится в результат или сообщение об ошибке.

## Запуск

Требования: Python 3.11 или 3.12 и [uv](https://docs.astral.sh/uv/).

```bash
cd roboflow-test
uv sync --group dev
export ROBOFLOW_API_KEY='ваш-ключ'
uv run roboflow-dice-test ../photo.jpg
```

Порог можно задать аргументом:

```bash
uv run roboflow-dice-test ../photo.jpg --confidence 0.6
```

Сокращённый формат ответа:

```json
{
  "has_dice": true,
  "count": 1,
  "model_id": "dnd-dices-ycaiz/2",
  "detections": [
    {
      "label": "d20",
      "confidence": 0.92,
      "box": {"x_min": 35.0, "y_min": 30.0, "x_max": 65.0, "y_max": 50.0}
    }
  ]
}
```

Доступные переменные приведены в `.env.example`. Файл `.env` намеренно игнорируется, но
автоматически не загружается: экспортируйте переменные в shell или используйте менеджер
секретов. Не коммитьте API-ключ.

## Проверки без сети

```bash
uv run pytest -q
uv run ruff check .
uv run mypy
```

Тесты подменяют Roboflow-клиент и не требуют API-ключа, сетевого доступа или оплачиваемых
вызовов. Живой smoke test выполняется только явным запуском CLI.

## Ограничения

- Результат зависит от доступности и текущей версии удалённого сервиса Roboflow.
- Публичная модель — только исходная точка; качество нужно измерить на собственных фото и
  отрицательных примерах.
- По умолчанию используется облачный inference, поэтому фотографии покидают сервер.
- Набор данных модели опубликован под CC BY 4.0; перед коммерческим использованием проверьте
  условия Roboflow и атрибуцию источника.
