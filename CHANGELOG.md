# История изменений

## 0.1.0 — 2026-10-09

- Добавлен CPU-inference стандартных RPG-кубиков через ONNX Runtime.
- Добавлены CLI, HTTP API, проверки размера изображений и readiness endpoint.
- Добавлена проверяемая загрузка зафиксированной версии модели после явного принятия лицензии.
- Добавлены Docker-конфигурация и автоматические тесты preprocessing, NMS, API и downloader.
- Порт API по умолчанию изменён на свободный локальный порт `18080`.
- Порог confidence по умолчанию повышен до `0.85`, чтобы отсеивать детекции с более низким score.
- Крупные фото теперь безопасно уменьшаются перед inference вместо отклонения по мягкому лимиту пикселей.
- Добавлен консервативный high-confidence fallback для сложных кадров: согласование преобразованных вариантов и контекстно ограниченная проверка фрагментов повышают recall без снижения порога `0.85`.
